# 森森物语 · 心理陪伴 App

一个人从零做出来的自我理解型陪伴 App：森森兔不是心理治疗师，但可以陪你整理情绪、看见自己的模式，并且**记得你**。

这个仓库是展示页，不含源码。

数据库优先：记忆、心情和日记都存在自己设备上的 SQLite 里，AI 聊天只是可以替换的一层。

***

## 它是什么

- **长期记忆**：8 大类结构化记忆，支持合并、更新、版本管理和证据链；新记忆先进「待审」，确认后才生效
- **每轮先规划再回复**：先判断用户此刻的状态，再分配角色（共情 → 点明需求 → 主回复 → 收束锚点）
- **心理知识卡**：依恋、IFS、CBT、ACT、创伤知情等视角，对话时按需引用
- **每次对话生成总结**：journal + 关键记忆，积累成心情轨迹与日历视图
- **今日首页**：每天早上自动生成一句早安、内容推荐和今日句子，按用户自己的记忆来选
- **三只兔子，三种声线**：语音回复，每个角色一个声线
- **Mac 原生 app + 手机网页**：同一份数据，同一个对话大脑

## 技术概览

| 部分 | 做法 |
|---|---|
| Mac app | Swift / SwiftUI，直接打开本地 SQLite（WAL） |
| 手机端 | Python 服务 + 网页，经 Tailscale 私有访问，不暴露公网 |
| 每日任务 | Python，launchd 每天 7:30 生成今日首页 |
| 对话 | DeepSeek；记忆提取、总结、危机安全逻辑和对话共用一套 |
| 语音 | edge-tts |
| 数据 | 本地 SQLite，真实数据只有一份，写之前先做快照 |

***

## 🎯 产品原则

1. 第一目标是帮助用户获得自我理解，不是替代治疗
2. 所有功能都要服务「被理解感、准确度、边界感、长期记忆质量」
3. 先做深，不做多
4. 不用功能数量证明价值
5. 每次迭代都要能被体验和评分

## 📌 关于本项目的原创性

本项目包含原创的产品设计和技术架构思路，这些是经过长期思考和迭代形成的：

- 🎯 **「本轮策略规划器」**：先理解用户状态、再规划角色分工的模式
- 🎭 **四角色响应结构**：empathy(共情) → need(需求点明) → main(主回复) → anchor(收束锚点)
- 🧠 **长期状态画像系统**：跨会话的用户心理状态追踪和版本管理
- 📚 **结构化记忆分类**：8 大记忆类别，支持合并、更新和证据链
